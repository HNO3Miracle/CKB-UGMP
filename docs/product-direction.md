# CKB-UGMP 产品化方向说明

更新时间：2026-06-03

## 定位调整

根据阶段性反馈，项目后续明确转向完整产品化落地，而不是继续以开发者教程或技术演示为主。

新的主路径是：

1. 用户上传图片。
2. 系统自动生成铸造预览。
3. 用户连接钱包并确认费用。
4. 用户签名后创建 Spore / DOB。
5. 用户在展示大厅查看自己的 DOB 和链上状态。

## 本次界面调整

- 首页文案从 “Prototype / Sprint Focus” 调整为终端用户能理解的 “一键创建 DOB”。
- 弱化存储协议、metadata、RPC 等开发者术语。
- 工作台改为“创建新的 DOB”，强调选图、上传、预览、签名铸造。
- 展示大厅改为“我的 DOB 展示大厅”，突出资产查看和链上状态。
- 增加费用提示，说明当前采用用户自付链上交易费用。
- 默认隐藏技术详情，只在用户点击“高级详情”时展示。
- 去掉首页的承诺/路线卡片，让用户直接进入创建流程。

## 费用优化方向

当前阶段采取以下策略降低普通用户理解和使用成本：

- 图片本体保存到 IPFS，不直接把大图片写入链上。
- 链上只保存最小 metadata 和资源引用。
- 图片按原图上传，不在客户端压缩，避免改变用户资产本体。
- 正式签名前明确提示费用需要由用户确认。
- dry-run / 预览模式不触发签名，也不会产生链上费用。

后续还需要继续评估：

- 批量铸造或聚合交易
- 费用预估展示
- 赞助交易或代付模式

## 下一步

- 增加更清晰的费用预估模块。
- 继续完善展示大厅的链上 Spore / DOB 内容解析。
- 解决 JoyID / WebAuthn 签名阻塞问题。
- 把开发者细节移动到文档或高级区域，不再作为首页主路径。
